## 1. 获取 wafer_cpp 配方

在右侧“wafer_cpp 配方”区域，选择以下一种方式：

- 点击“刷新配方”，从 MySQL 重新读取当前模式的配方。
- 点击“导入配方”，选择 wafer_cpp 导出的 JSON 文件。文件内容可以是一个配方对象或配方对象数组；每个配方需包含 `recipe_name` 和对象格式的 `params_json`。程序只载入结构与当前 `5um` 或 `20um` 模式匹配的配方。

导入成功后，从“配方”下拉框选择目标配方。导入只替换当前界面中的配方列表，不写入 MySQL。切换模式或刷新配方后，应重新确认下拉框中选中的配方。

## 2. 检查本次运行参数和模型

1. 打开右侧“参数预览”页，检查当前配方的检测和裁剪参数。
2. 如需调整参数，在对应输入框修改并结束编辑。参数格式错误时会恢复原值并弹出提示。修改只作用于当前运行配方，不写入数据库或导入文件；重新选择配方会载入该配方的原始参数。
3. 检查模型路径。5um 的盲元电路区模型选择有效的 `.engine` 或 `.onnx` 文件；20um 选择有效的 TorchScript `.pt` 文件。可点击模型路径旁的“选择模型文件”。模型路径无效时，程序会阻止检测并提示。
4. “操作”页的阈值滑块用于二值图预览。若要把当前阈值用于本次 Pad 处理，点击“写入当前配方”；该操作只更新当前运行配方中的 `padGrayThresh`。

## 3. 5um 图像处理

1. 点击“选择单张图”加载一张图片，或点击“选择裁剪图文件夹”加载文件夹。两种输入互斥，后选择的路径会清除之前的路径。选择文件夹后，主视图显示按文件名自然排序的第一张，可用“上一张”“下一张”切换。
2. 在“参数预览”页检查配方区域框。可在图中拖动区域框或调整边缘，也可通过“区域框微调”输入坐标。本次检测和按配置框裁剪使用微调后的坐标。
3. 点击“检测单张”检测当前显示的图片；选择裁剪图文件夹后也可点击“批量检测”逐张检测。完成后在“检测结果”视图及缺陷列表中查看结果。
4. 如需批量裁剪，选择裁剪图文件夹后点击“批量裁剪盲元电路外围区”或“按配置框批量裁剪”。输出默认位于输入文件夹同级的 `split` 文件夹，并分别保存到 `blind`、`circuit`、`outer` 子文件夹。裁剪期间可点击“停止裁剪”。

5um 单张检测使用当前显示的图片；批量检测逐张读取裁剪图文件夹。自动裁剪和“裁剪保存”可用于单图 ROI 裁剪，与检测操作相互独立。

## 4. 20um 单批自动裁剪与检测

1. 在左侧选择正确的“机台配方”和小图文件夹。确认文件夹内图片按文件名自然排序后，前一完整批次对应同一晶圆位置。默认 20um 配方每批为 8 张，实际以所选机台配方为准。
2. 如需裁剪，点击“操作”页的“自动裁剪”。程序从文件夹中的第一批小图生成上图、下图，完成窗口分割与定位后，在原图上生成可编辑的裁剪框。
3. 调整裁剪框并点击“裁剪保存”，保存所需区域。
4. 如需检测，在“参数预览”页点击“检测单张”。程序会重新读取文件夹第一批小图、生成上下图并运行检测；无需预先点击“拼接单张”或“自动裁剪”。

自动裁剪完成后可在原图上微调裁剪框；“检测单张”会独立处理第一批小图，不会读取手动调整后的裁剪框。

## 5. 20um 全部检测

1. 确认机台配方、小图文件夹、wafer_cpp 配方和 `.pt` 模型路径。
2. 在“参数预览”页点击“全部检测”。程序按自然排序后的完整批次逐批拼接和检测，第一批完成后即可查看结果。
3. 使用检测结果视图旁的“上一张”“下一张”切换已完成批次；下方显示当前批次的缺陷数量和明细。
4. 如需提前结束，再次点击已变为“停止检测”的按钮。程序结束当前处理后停止，已完成批次的结果仍可查看。

末尾不足一批的小图会跳过，并在操作日志中提示数量。全部检测结果保留在当前程序会话中；开始新一次检测会清除上一次检测列表。

## 6. 查看结果与常见提示

- “检测结果”视图显示标注后的图像；右侧结果框显示缺陷数量、算法、类型、外接框宽高、面积，以及有值时的深浅度或置信度。
- “操作日志”显示配方载入、自动裁剪、逐批检测和报错信息。检测失败时先查看弹窗及日志中的具体原因。
- 提示“请先选择有效的小图文件夹”：20um 自动裁剪和检测需要有效的小图文件夹；核对路径与机台配方。
- 提示“请先加载或拼接待检测图像”：5um 单张检测前需加载图片，或选择含图片的裁剪图文件夹。
- 提示“模型文件无效”：在“参数预览”页选择当前模式对应的模型文件，并确认文件仍存在。
- 提示配方读取失败：检查 MySQL 连接，或使用“导入配方”选择符合当前模式的 JSON 文件。
- 提示自动裁剪失败或未返回裁剪框：检查当前配方、输入图像和操作日志；不要把未生成的裁剪框当作有效结果。
