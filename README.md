# 图像拼接与二值化工具

基于 PySide6、OpenCV 和 NumPy 的 Windows 桌面工具。切换 5um 或 20um 模式后，可按机台参数拼接显微小图，并使用当前模式的 wafer_cpp 配方进行裁剪和检测。

## 两种模式共有的功能

- 按当前模式的机台参数拼接文件夹中的小图，可拼接单张或全部完整批次，预览并保存当前拼接图。图片按文件名自然排序，末尾不足一批的图片会跳过。
- 加载单张图片，或拖入图片、文件夹。支持原图、二值图、并排、裁剪图和检测结果视图；并排视图的缩放和平移同步。
- 调整 0 至 255 的二值化阈值，计算灰度均值，按配方参数定位第一个 Pad 或所有 Pad；“写入当前配方”仅更新本次运行使用的参数。
- 以 0.05° 步进旋转图片；按住 `W` 在原图上画 ROI，拖动或调整大小后用“裁剪保存”导出 JPEG、PNG 或 BMP。按住 `R` 可进行图像测量。
- 管理当前模式的机台拼接参数，打开拼接标定画布；查看和调整 wafer_cpp 运行配方中的参数。
- 启动时从 MySQL 读取当前模式的 wafer_cpp 配方，也可点击“导入配方”读取 wafer_cpp 导出的 JSON。文件导入只替换本次会话的配方列表，不写入数据库。数据库不可用时仍可导入。

## 环境安装

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 5um 模型转换为 TensorRT Engine

在 `circuit.onnx` 所在目录执行以下命令，`trtexec` 需已加入 `PATH`。命令将动态 batch 固定为本项目使用的 batch 1；同名 Engine 会被覆盖。

```powershell
trtexec --onnx=circuit.onnx --saveEngine=circuit_fp16.engine --fp16 --shapes=image:1x3x512x512 --skipInference
```

## 5um 功能

1. 切换到 `5um`，选择机台拼接参数和对应的 wafer_cpp 配方。小图文件夹可用于拼接；单张图片或拼接结果可作为自动裁剪的输入。
2. 点击“自动裁剪”，根据当前运行配方生成可微调的裁剪框；确认后点击“裁剪保存”。也可直接加载已裁剪图片，或用“选择裁剪图文件夹”预览文件夹中的图片。
3. 在参数预览中查看、编辑检测参数，并微调盲元、电路、外围等区域框。选择有效的 5um `.onnx` 检测模型及盲元/电路/外围区 `.engine` 或 `.onnx` 模型后，可“检测单张”；选择裁剪图文件夹后可“批量检测”，逐张查看结果。
4. 对裁剪图文件夹可执行“批量裁剪盲元电路外围区”或“按配置框批量裁剪”，将区域图保存到所选目录。批量任务可停止。

5um 拼接参数使用单层图像，行列数由机台配方决定。检测使用当前选择的 wafer_cpp 配方及界面中本次修改的参数。

## 20um 功能

1. 切换到 `20um`，选择机台拼接参数和对应的 wafer_cpp 配方。选择小图文件夹后，可拼接一批或全部完整批次，并切换查看上图、下图。
2. “自动裁剪”会从小图文件夹生成上下两层图像，再按配方生成可微调的裁剪框；确认后可用“裁剪保存”导出当前图像的 ROI。
3. 检测小图文件夹时，选择有效的 20um `.pt` 模型，点击“检测单张”处理首批，或点击“全部检测”逐批处理并查看结果。
4. 也可用“选择已裁剪上图”“选择已裁剪下图”直接指定一张或两张已裁剪图，然后点击“检测单张”。这种输入不支持“全部检测”；仅选下图时无需 `.pt` 模型。

20um 拼接参数使用上下两层图像；拼接后默认以下图作为旋转、二值化和手动 ROI 裁剪的工作图像。

## 配方与操作说明

“刷新配方”从 MySQL 读取当前分辨率的 wafer_cpp 配方。“导入配方”支持单个配方对象或配方数组；每项应包含 `recipe_name` 和对象形式的 `params_json`，并与当前 5um/20um 模式匹配。切换模式后需选用对应模式的配方。

小图文件夹支持 `.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff` 和 `.webp`。全部拼接可通过下拉框、“上一张”“下一张”或左右方向键切换批次；阈值控件有焦点时，左右方向键用于调节阈值。ROI 只能在原图或并排模式的原图侧编辑，裁剪保存使用旋转后的原图。

## 拼接参数

拼接参数模板位于 `resources/params_20um.json` 和 `resources/params_5um.json`，运行时修改后的配方保存在程序目录下的 `config` 文件夹。两者格式一致，每个机台包含以下字段。5um 的行列数由配方指定；3 行 3 列时蛇形 ID 顺序为 `0,1,2 / 5,4,3 / 6,7,8`。

单击“管理配方”可查看、新增、修改、删除和刷新当前模式的配方。保存后主界面的机台列表会立即刷新；首次修改时会从内置模板创建 `config` 下的可写配方文件。

配方管理页面左上角可设置当前模式的像素尺寸，20um 默认为 `2.5 μm/pix`，5um 默认为 `1.43 μm/pix`。该设置保存在界面配置中，不写入配方 JSON。绘制裁剪框后，裁剪保存按钮附近会实时显示将裁剪框中心移动到图像中心所需的水平和垂直偏移，单位为毫米。

- `hDx`、`hDy`：水平方向相邻图片的机械偏移。
- `vDx`、`vDy`：垂直方向相邻图片的机械偏移。
- `rows`、`cols`、`layers`：拼接网格行数、列数和层数。
- `singleW`、`singleH`：输入小图的宽度和高度。
- `channel`：输入图像通道数。

源码运行时从项目目录读取该文件。打包程序优先读取可执行文件同目录下的同名文件，未找到时读取打包内置参数。
